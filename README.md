One original excuse from a GPS that swears the wrong road was a shortcut — the funniest line wins. The program writes a single line to `/output/entry.txt`:

> The map swore this cul-de-sac was a shortcut, and I trust the map more than I trust your eyes.

Smug, defensive, and blaming the map — exactly as a GPS caught red-handed would sound. The entry is fully deterministic: no network, no randomness, no clock — the same 94 bytes on every run.

## Run it

```sh
node main.ts
```

`main.ts` runs on Node 22.18 or later (TypeScript as-is) and writes `entry.txt` into `/output` (or `$MAKEFUN_OUTPUT_DIR` when set).
